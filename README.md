# Australia-Data-Analyst-job-Analysis
Australia Data Analyst Job Analysis using Python in Microsoft Fabric. This project explores Australian data analyst job market trends, salary patterns, job titles, experience levels, employment types, company locations, remote work, and company sizes using Pandas, Matplotlib, and Seaborn.


# Project Overview

- This project focuses on analysing the Australian Data Analyst job market using Python. The objective is to explore salary patterns, job opportunities, experience requirements, employment types, company locations, remote work arrangements, and company sizes.

-The analysis helps understand salary trends and different aspects of the Data Analyst job market in Australia.
